## Ejercicio práctico integrador

Se revisa el sitio real del estudiante, tal como está después de las tareas de las clases 1-4 (no se pide crear nada nuevo). Debe cumplir:

- Estructura HTML válida (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`) — Clase 1.
- Las 3 secciones de contenido propio: Inicio, Sobre mí/proyecto, Galería o servicios — Clase 2.
- CSS vinculado correctamente, con paleta de colores y tipografía aplicadas de forma consistente — Clase 3.
- Meta etiqueta viewport y al menos una media query, sin errores visuales en vista celular ni computadora — Clase 4.

Puntos: 40
