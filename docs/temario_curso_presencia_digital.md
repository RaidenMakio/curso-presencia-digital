# Curso B: Crea tu Presencia Digital
**Duración:** 8 clases | **Dirigido a:** Estudiantes de colegio, sin experiencia previa en programación

## Objetivo principal del curso
Que el estudiante diseñe, construya y publique su propio sitio web con identidad visual propia (generada con IA), obteniendo un link real y funcional que pueda compartir al finalizar el curso.

---

## Clase 1: Definición del proyecto + estructura básica (HTML)
**Objetivos específicos:**
- Definir la idea de proyecto (portafolio, emprendimiento o marca personal)
- Aprender la estructura básica de una página web con HTML

**Entregables:**
1. Idea de proyecto definida por escrito
2. Primer archivo HTML con estructura mínima
3. Boceto/esquema de las secciones del sitio

---

## Clase 2: Secciones de contenido (inicio, sobre mí/proyecto, galería o servicios)
**Objetivos específicos:**
- Aplicar etiquetas HTML para organizar texto, imágenes y listas
- Redactar contenido propio para cada sección

**Entregables:**
1. Sección "Inicio" con texto propio
2. Sección "Sobre mí/proyecto" completa
3. Sección de galería o servicios con al menos 2 elementos

---

## Clase 3: Estilo visual (CSS): colores y tipografía
**Objetivos específicos:**
- Vincular CSS al HTML
- Definir y aplicar una identidad visual coherente (colores y tipografía)

**Entregables:**
1. Paleta de colores definida y aplicada
2. Tipografía elegida y aplicada
3. Archivo CSS vinculado correctamente

---

## Clase 4: Diseño responsive (celular y computadora)
**Objetivos específicos:**
- Aprender el uso básico de media queries y unidades flexibles
- Verificar la visualización del sitio en distintos dispositivos

**Entregables:**
1. Sitio ajustado en vista celular
2. Sitio ajustado en vista computadora
3. Corrección de espaciados/tamaños

---

## Clase 5: Banner/logo con IA generativa de imágenes
**Objetivos específicos:**
- Escribir prompts efectivos para generación de imágenes con IA
- Integrar la imagen generada al diseño del sitio

**Entregables:**
1. Banner o logo generado con IA
2. Imagen optimizada e insertada en el sitio
3. Ajuste de tamaño/posición del banner

---

## Clase 6: Enlaces, redes sociales y contacto
**Objetivos específicos:**
- Crear enlaces funcionales e íconos de redes sociales
- Incorporar una vía de contacto clara

**Entregables:**
1. Enlaces a redes sociales funcionando
2. Sección o botón de contacto
3. Verificación del funcionamiento de todos los enlaces

---

## Clase 7: Ajustes finales y práctica guiada
**Objetivos específicos:**
- Aplicar retroalimentación para corregir errores visuales y de contenido
- Revisar la coherencia general del sitio

**Entregables:**
1. Lista de correcciones aplicadas
2. Sitio revisado sección por sección
3. Versión "casi final" lista para publicar

---

## Clase 8: Publicación y presentación final
**Objetivos específicos:**
- Aprender el proceso de publicación gratuita del sitio
- Presentar y compartir el resultado final

**Entregables:**
1. Sitio publicado con link funcional
2. Presentación del sitio ante el grupo
3. Link compartido en redes sociales propias
