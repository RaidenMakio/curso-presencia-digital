# Recursos — Clase 1: Definición del proyecto + HTML

Material **opcional** para profundizar con calma. No hace falta leerlo para la clase ni para la tarea. 🇪🇸 = en español · 🇬🇧 = en inglés (el navegador puede traducirlo).

## Para leer con calma

- 🇪🇸 [Tu primer sitio web — MDN](https://developer.mozilla.org/es/docs/Learn_web_development/Getting_started/Your_first_website): el recorrido oficial para principiantes; es la misma idea de la clase, con más detalle.
- 🇪🇸 [Estructurar contenido con HTML — MDN](https://developer.mozilla.org/es/docs/Learn_web_development/Core/Structuring_content): índice de artículos cortos sobre HTML, en orden de dificultad.
- 🇪🇸 [Sintaxis básica de HTML — MDN](https://developer.mozilla.org/es/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax): etiquetas, atributos y anidación (lo de "abrir y cerrar").
- 🇪🇸 [Estructura de un documento HTML — MDN](https://developer.mozilla.org/es/docs/Learn_web_development/Core/Structuring_content/Structuring_documents): `head`, `body`, encabezado, pie y por qué se ordena así.
- 🇬🇧 [Learn HTML — web.dev](https://web.dev/learn/html): curso gratuito de Google, con explicaciones muy visuales.
- 🇪🇸 [Curso de Diseño Web Responsivo — freeCodeCamp](https://www.freecodecamp.org/espanol/learn/2022/responsive-web-design/): ejercicios paso a paso que se corrigen solos. Ideal para seguir después del curso.

## Cheatsheets (para tener abiertas mientras trabajás)

- 🇬🇧 [HTML Cheat Sheet](https://htmlcheatsheet.com/): las etiquetas más usadas, en una sola página.
- 🇪🇸 [Referencia de elementos HTML — MDN](https://developer.mozilla.org/es/docs/Web/HTML/Reference/Elements): la lista completa; buscala con Ctrl + F cuando dudes de una etiqueta.

## Herramientas

- [Visual Studio Code](https://code.visualstudio.com/): editor de código gratuito.
- [Live Server (extensión de VS Code)](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer): recarga el navegador solo cada vez que guardás.
- [Validador de HTML — W3C](https://validator.w3.org/): pegás tu código y te marca etiquetas mal cerradas.

## Si algo no funciona

- 🇪🇸 [Depurar HTML — MDN](https://developer.mozilla.org/es/docs/Learn_web_development/Core/Structuring_content/Debugging_HTML): cómo encontrar y arreglar errores típicos.
