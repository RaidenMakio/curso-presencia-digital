# Imágenes de la presentación de la Clase 1

`presentacion.html` busca acá las imágenes de los ejemplos visuales. Copiá cada archivo con **el nombre exacto** de la tabla (sin importar la extensión: `.jpg`, `.png`, `.webp`, `.jpeg`, `.svg` o `.gif`). Si falta una, la diapositiva muestra un recuadro punteado con el nombre esperado.

| Diapositiva | Archivo | Qué mostrar |
|---|---|---|
| 5 | `casa-negocio` | Casa pensada para un negocio (entrada clara, mostrador) |
| 5 | `casa-estudio` | Casa-estudio con paredes limpias para exhibir arte |
| 5 | `casa-propia` | Casa cómoda para vivir y recibir visitas |
| 6 | `analogia-plano` | El plano: definir el proyecto |
| 6 | `analogia-html` | Cimientos y paredes: la estructura HTML |
| 6 | `analogia-css` | Pintura y muebles: el estilo CSS |
| 9 | `pagina-suelta` | Contenido todo mezclado, sin distinguir partes |
| 9 | `pagina-con-partes` | Página con título, párrafo e imagen identificados |
| 17 | `html-sin-estilo` | Una página solo con HTML |
| 17 | `html-con-css` | La misma página con CSS |
| 20 | `anidar-bien` | Cajas bien anidadas (la chica se cierra primero) |
| 20 | `anidar-mal` | Cajas mal anidadas (la chica queda colgando) |
