Objetivo: anclaje mental. Cimientos (Clase 1) → habitaciones (Clase 2) → decoración (hoy). La analogía se retoma en los bloques 2 y 3.

Dos casas con las mismas habitaciones

✗ Sin plan de decoración

Un color distinto en cada cuarto, cuatro estilos de silla, una letra distinta en cada cartel. Cansadora: parece cinco lugares distintos.

✓ Con identidad coherente

Tres colores y un solo estilo de mueble, repetidos en todas partes. Se recuerda y se siente “de alguien”.

Identidad visual coherente = pocos elementos, repetidos siempre igual.

¿Cómo se decora sin ir cuarto por cuarto?

📖 El manual de decoración

Una hoja con reglas: “todas las paredes de este color, todos los carteles con esta letra”. En la web es el archivo CSS (style.css).

📣 Avisarle al decorador

Hay que decirle que el manual existe y dónde está. En la web es la etiqueta <link> dentro del <head>.

🎨 Cada regla, para toda la casa

Una regla se aplica a todos los títulos, todos los textos, de una sola vez. Cambiás el manual y cambia todo.

Tramo A · Vincular CSS al HTML

Se escribe aparte y se conecta con <link>

<head>
  <title>Valeria Fotografía</title>
  <link rel="stylesheet" href="style.css">
</head>

rel="stylesheet"

Le dice al navegador: “esto es una hoja de estilos”.

href="style.css"

Dónde está el archivo. Como el src de una imagen: si el nombre no coincide, no carga.

Va dentro del <head>, nunca en el <body>. Y no tiene etiqueta de cierre.

Chequeo rápido

  • B) <link>
  • C) <css>
  • D) <script>

B) <link>

Tramo A · Vincular CSS al HTML

Cada regla tiene tres partes

h1 {
  color: #2b2b2b;
  font-family: Georgia, serif;
}

Selector

h1 — a qué etiqueta(s) le aplica.

Propiedad

color, font-family — qué característica se cambia.

Valor

#2b2b2b, Georgia, serif — a qué se cambia.

Llaves { }, dos puntos entre propiedad y valor, y ; al final de cada línea.

Chequeo rápido

En la regla h1 { color: #b23a48; }, ¿cuál es el selector?

  • A) color
  • B) #b23a48
  • C) h1
  • D) {}

C) h1

Chequeo rápido

  • A) Selector, propiedad, valor
  • B) Etiqueta, atributo, contenido
  • C) Header, body, footer
  • D) Clase, id, nombre

Tramo A · Vincular CSS al HTML

¿Solo una etiqueta? Marcala con class

<!-- HTML -->
<p class="destacado">
  ¡Escribime hoy mismo!
</p>
/* CSS */
.destacado {
  color: #b23a48;
}

class es un atributo, como src o alt. En CSS se apunta con un punto delante del nombre.

Chequeo rápido

  • A) id únicamente
  • B) class
  • C) style
  • D) link

B) class

Tramo A · Vincular CSS al HTML

Tres errores frecuentes: “no se me aplican los estilos”

1

Otra carpeta

El .html y el .css tienen que estar en la misma carpeta.

2

Otro nombre

style.css no es lo mismo que Style.css ni estilos.css. Tiene que coincidir letra por letra.

3

Mal armado

Falta rel="stylesheet", o el <link> quedó en el <body>.

Truco: después de vincular, probá con una sola regla (por ejemplo, un color de fondo). Si cambia, está bien conectado.

Tramo B · Identidad visual coherente

Tipografía: máximo 2 fuentes

Una para los títulos

Valeria Pérez — Fotógrafa

Georgia, serif

Otra para el texto

Capturo momentos únicos.

Verdana, sans-serif

Web-safe (Arial, Georgia, Verdana): ya están instaladas en casi todos los dispositivos. Lo más simple para empezar.

Google Fonts: muchas más opciones, pero hay que importarlas y dependen de internet.

Ejemplo práctico

Definilo una vez en body; los títulos, aparte

body {
  background-color: #faf7f2;
  color: #2b2b2b;
  font-family: Verdana, sans-serif;
}

h1, h2 {
  color: #b23a48;
  font-family: Georgia, serif;
}
Valeria Pérez — Fotógrafa

Capturo momentos únicos en cumpleaños, quince años y eventos pequeños.

Sobre mí

Empecé a fotografiar hace 3 años en cumpleaños de amigos.

Todo lo que está dentro de body lo hereda: se aplica a toda la página de una vez y es más fácil mantenerla coherente. h1, h2 con coma = la misma regla para las dos.

45 min Bloque 3

Del ejemplo a tu sitio

Primero en vivo con un/a voluntario/a, después cada uno con el suyo.

Bloque 3 · Pedimos un/a voluntario/a con su archivo de la Clase 2

Lo hacemos en vivo sobre un proyecto real

  1. Elegimos su paleta. Repasamos su brief (¿alegre, serio, elegante, cercano?), fijamos 3 colores —principal, texto y fondo— y verificamos el contraste.
  2. Creamos style.css en la misma carpeta y agregamos el <link> en el <head>. Probamos con una sola regla para confirmar que está conectado.
  3. Aplicamos paleta y tipografía al body, a h1, h2 y a un elemento destacado con class.

El resto sigue por pantalla y puede sugerir en el chat.

Bloque 3 · Ahora vos, con tu propio archivo

Tres pasos, con tu propio estilo

  1. Definí tu paleta de 2-3 colores y tu tipografía, acordes a tu proyecto.
  2. Creá style.css y vinculalo en el <head> con <link rel="stylesheet" href="style.css">.
  3. Aplicá paleta y tipografía al body, a los títulos (h1/h2) y a algún elemento destacado.

Tu elección es tuya: ni la de Valeria ni la del voluntario.
