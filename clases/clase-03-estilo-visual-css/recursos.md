# Recursos — Clase 3: Estilo visual (CSS): colores y tipografía

Material **opcional** para profundizar con calma. No hace falta leerlo para la clase ni para la tarea. 🇪🇸 = en español · 🇬🇧 = en inglés (el navegador puede traducirlo).

## Para leer con calma

- 🇪🇸 [¿Qué es CSS? — MDN](https://developer.mozilla.org/es/docs/Learn_web_development/Core/Styling_basics/What_is_CSS): la idea de "el manual de decoración", con más detalle.
- 🇪🇸 [Primeros pasos con CSS — MDN](https://developer.mozilla.org/es/docs/Learn_web_development/Core/Styling_basics/Getting_started): cómo vincular `style.css` y escribir tus primeras reglas.
- 🇪🇸 [Estilos de texto: fundamentos — MDN](https://developer.mozilla.org/es/docs/Learn_web_development/Core/Text_styling/Fundamentals): `font-family`, tamaño, peso e interlineado.
- 🇪🇸 [Colores en CSS — MDN](https://developer.mozilla.org/es/docs/Web/CSS/CSS_colors): formatos de color (`#hex`, `rgb`, nombres) y cuándo usar cada uno.
- 🇬🇧 [Learn CSS — web.dev](https://web.dev/learn/css): curso gratuito de Google, con ejemplos interactivos.
- 🇬🇧 [Learn Design — web.dev](https://web.dev/learn/design): cómo elegir colores, espacios y tipografía sin ser diseñador/a.
- 🇬🇧 [Guía de Google Fonts (Knowledge)](https://fonts.google.com/knowledge): qué es una tipografía, cómo combinarlas y cómo elegirlas.

## Cheatsheets

- 🇬🇧 [CSS Cheat Sheet](https://htmlcheatsheet.com/css/): propiedades más usadas, en una sola página.
- 🇬🇧 [Nombres de colores CSS — W3Schools](https://www.w3schools.com/colors/colors_names.asp): los 140 colores con nombre, para probar sin memorizar códigos.
- 🇪🇸 [`font-family` — MDN](https://developer.mozilla.org/es/docs/Web/CSS/font-family): cómo declarar una tipografía con alternativa de respaldo.

## Herramientas para tu paleta y tu tipografía

- [Coolors](https://coolors.co/): generá paletas apretando la barra espaciadora; bloqueá el color que te guste y seguí probando.
- [Adobe Color](https://color.adobe.com/es/create): armá paletas a partir de una foto o de la rueda de color.
- [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/): verifica si el texto se lee sobre su fondo (buscá que diga "Pass").
- [Google Fonts](https://fonts.google.com/): tipografías gratuitas; te da el código para pegar en tu `<head>`.

## Si algo no funciona

- 🇪🇸 [Depurar CSS — MDN](https://developer.mozilla.org/es/docs/Learn_web_development/Core/Styling_basics/Debugging_CSS): qué revisar cuando tu estilo "no se aplica".
- [Validador de CSS — W3C](https://jigsaw.w3.org/css-validator/): marca errores de escritura en tu `style.css`.
