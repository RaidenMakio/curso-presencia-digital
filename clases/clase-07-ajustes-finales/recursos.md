# Recursos — Clase 7: Ajustes finales y práctica guiada

Material **opcional** para profundizar con calma. No hace falta leerlo para la clase ni para la tarea. 🇪🇸 = en español · 🇬🇧 = en inglés (el navegador puede traducirlo).

## Herramientas para revisar tu sitio

- [Validador de HTML — W3C](https://validator.w3.org/): encuentra etiquetas mal cerradas o mal ubicadas.
- [Validador de CSS — W3C](https://jigsaw.w3.org/css-validator/): errores de escritura en tu hoja de estilo.
- [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/): comprobá que el texto se lea sobre cada fondo.
- [Wave — WebAIM](https://wave.webaim.org/): revisa accesibilidad: `alt` faltantes, títulos, contraste.
- [PageSpeed Insights](https://pagespeed.web.dev/): mide qué tan rápido carga tu sitio y qué mejorar (las imágenes suelen ser la causa).
- [Squoosh](https://squoosh.app/) · [TinyPNG](https://tinypng.com/): comprimir imágenes pesadas.

## Para leer con calma

- 🇪🇸 [Depurar HTML — MDN](https://developer.mozilla.org/es/docs/Learn_web_development/Core/Structuring_content/Debugging_HTML): cómo buscar el error paso a paso.
- 🇪🇸 [Depurar CSS — MDN](https://developer.mozilla.org/es/docs/Learn_web_development/Core/Styling_basics/Debugging_CSS): qué revisar cuando un estilo no se aplica.
- 🇬🇧 [Design tips — W3C WAI](https://www.w3.org/WAI/tips/designing/): consejos cortos para que el sitio sea claro y usable.
- 🇬🇧 [Learn Design — web.dev](https://web.dev/learn/design): coherencia visual, espacios y jerarquía.
- 🇬🇧 [Learn Accessibility — web.dev](https://web.dev/learn/accessibility): revisión de accesibilidad de un sitio.
- 🇪🇸 [Curso de Diseño Web Responsivo — freeCodeCamp](https://www.freecodecamp.org/espanol/learn/2022/responsive-web-design/): repasar lo visto con ejercicios.

## Herramientas para probar en distintas pantallas

- 🇬🇧 [Modo dispositivo de Chrome DevTools](https://developer.chrome.com/docs/devtools/device-mode): simulá celulares y tablets con F12.
- [Am I Responsive?](https://ui.dev/amiresponsive): vista rápida en varios dispositivos.
- [Can I use…](https://caniuse.com/): compatibilidad de una propiedad con cada navegador.

## Tu lista de revisión final

1. ¿Todos los enlaces funcionan?
2. ¿Todas las imágenes tienen `alt` y pesan poco?
3. ¿El texto se lee bien sobre su fondo?
4. ¿Se ve bien en celular y en computadora?
5. ¿Le mostraste el sitio a otra persona y entendió de qué trata?
