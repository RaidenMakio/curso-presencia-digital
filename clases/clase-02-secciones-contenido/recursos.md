# Recursos — Clase 2: Secciones de contenido

Material **opcional** para profundizar con calma. No hace falta leerlo para la clase ni para la tarea. 🇪🇸 = en español · 🇬🇧 = en inglés (el navegador puede traducirlo).

## Para leer con calma

- 🇪🇸 [Estructurar contenido con HTML — MDN](https://developer.mozilla.org/es/docs/Learn_web_development/Core/Structuring_content): índice de artículos sobre títulos, párrafos, listas y énfasis.
- 🇪🇸 [Listas en HTML — MDN](https://developer.mozilla.org/es/docs/Learn_web_development/Core/Structuring_content/Lists): cuándo usar lista con puntos y cuándo numerada.
- 🇪🇸 [La etiqueta `<img>` — MDN](https://developer.mozilla.org/es/docs/Web/HTML/Element/img): `src`, `alt`, tamaño y buenas prácticas.
- 🇪🇸 [La etiqueta `<a>` (enlaces) — MDN](https://developer.mozilla.org/es/docs/Web/HTML/Element/a): la referencia completa de los enlaces.
- 🇬🇧 [Cómo escribir un buen texto alternativo (alt) — W3C](https://www.w3.org/WAI/tutorials/images/): ejemplos de qué poner (y qué no) en el `alt` de cada imagen.
- 🇬🇧 [Learn Accessibility — web.dev](https://web.dev/learn/accessibility): por qué un sitio bien estructurado lo puede usar todo el mundo.
- 🇬🇧 [Design tips — W3C WAI](https://www.w3.org/WAI/tips/designing/): consejos cortos para que tus textos y secciones se lean con claridad.

## Cheatsheets

- 🇬🇧 [HTML Cheat Sheet](https://htmlcheatsheet.com/): etiquetas de texto, listas e imágenes en una sola página.
- 🇪🇸 [Referencia de elementos HTML — MDN](https://developer.mozilla.org/es/docs/Web/HTML/Reference/Elements): la lista completa de etiquetas.
