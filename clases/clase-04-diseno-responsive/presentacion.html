Los muebles no cambian: cambia cómo los acomodás según el tamaño del cuarto. Si en el departamento chico dejaras todo como en la casa grande, no podrías ni pasar.

Una página web es lo mismo: el contenido son los muebles y la pantalla es el cuarto.

¿Cómo se ve esto en una página web?

📐 El cuarto

Es la pantalla del dispositivo: celular, tablet o computadora.

📏 Decirle el tamaño real

Es la etiqueta viewport. Sin ella, el celular “se hace el grande”.

🔀 “Si es chico, acomodalo así”

Es una media query (@media).

Y los muebles que se estiran o achican para entrar son las unidades flexibles (%, rem, vw), en vez de tamaños fijos en px.

Tramo A · Viewport y media queries

Un sitio responsive se ve bien en cualquier pantalla

Mismo contenido, otra manera de acomodarlo. Dos piezas lo hacen posible: el viewport y las media queries.

Tramo A · Viewport y media queries

Sin viewport, el celular “se hace el grande”

Tramo A · Viewport y media queries

Una línea en el <head>, siempre

<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Valeria Fotografía</title>
  <link rel="stylesheet" href="style.css">
</head>

Sin esta línea, ningún ajuste responsive funciona bien en celular. Va en toda página.

Chequeo rápido

¿Qué meta etiqueta es necesaria en el <head> para que el diseño responsive funcione en celular?

  • A) <meta name="viewport">
  • B) <meta name="responsive">
  • C) <meta charset="utf-8">
  • D) <meta name="mobile">

A) <meta name="viewport">

Tramo A · Viewport y media queries

Media query: “si el cuarto es chico, acomodalo así”

/* Por defecto: pantallas grandes */
h1 {
  font-size: 40px;
}

/* Solo si la pantalla mide 600px o menos */
@media (max-width: 600px) {
  h1 {
    font-size: 28px;
  }
}

@media

Inicia la media query.

(max-width: 600px)

La condición: “600px de ancho o menos”. Ese ancho es el breakpoint.

Reglas adentro

Son reglas normales. Pisan a las de afuera solo cuando se cumple la condición.

Tramo A · Probalo vos

Achicá la pantalla y mirá cómo cambia

Valeria Fotografía

Capturo momentos únicos en cumpleaños y eventos pequeños.

Vista computadora: 3 columnas y título grandeVista celular (600px o menos): 1 columna y título chico

En un sitio real, la media query mira el ancho de la pantalla; acá el control simula esa pantalla achicándose.

Mover el control. El cambio ocurre en 600px (el breakpoint). Usa container queries solo para poder simular dentro de la diapositiva; la idea es la misma que @media (max-width: 600px). Hacer clic afuera del control para volver a navegar con las flechas.

Tramo A · Viewport y media queries

Tres errores frecuentes: “mi media query no funciona”

1

Está arriba de todo

El CSS se lee de arriba abajo: la regla que va después gana. Las media queries van al final del archivo.

2

Faltan llaves

@media lleva dos pares de llaves: uno para la media query y otro para cada regla adentro.

3

Falta el viewport

Sin la meta etiqueta, el celular no usa su ancho real y la media query “no se nota”.

Tramo B · Unidades flexibles y verificar

Los muebles de tamaño fijo no entran en el cuarto chico

width: 400px →→→

✗ Medida fija (px)
En un celular angosto se sale de la pantalla.

width: 100%

✓ Medida flexible (%)
Se adapta al ancho disponible.

Tramo B · Unidades flexibles y verificar

Tres unidades flexibles

%

Relativo al contenedor.

width: 90% = el 90 % de su caja madre.

rem

Relativo al tamaño de fuente base de la página.

padding: 2rem: textos y espacios que escalan juntos.

vw / vh

Relativo al ancho / alto de la ventana del navegador.

width: 50vw = la mitad del ancho de la ventana.

Regla práctica: para anchos, %; para textos y espacios, rem. px queda para detalles pequeños, como bordes.

  • C) pt

Tramo B · Unidades flexibles y verificar

Imágenes que se adaptan: width + max-width

.galeria img {
  width: 100%;
  max-width: 400px;
}

width: 100%

Se adapta al ancho disponible: nunca se sale en el celular.

max-width: 400px

En pantalla grande no crece de más: se queda en 400px.

Ejemplo práctico

Todo junto: viewport, imágenes flexibles y una media query

<!-- en el head -->
<meta name="viewport"
      content="width=device-width,
               initial-scale=1">
.galeria img {
  width: 100%;
  max-width: 400px;
}

@media (max-width: 600px) {
  body { font-size: 16px; }
  .galeria img { max-width: 100%; }
}

Las imágenes nunca pasan de 400px en pantalla grande, ocupan todo el ancho en celular, y el texto queda cómodo de leer en pantallas chicas.

Bloque 3 · Ejemplo guiado ≈10 min · Sitio de Valeria (o de un/a voluntario/a)

Lo hacemos en vivo

  1. Modo celular. F12 → ícono de celular (≈375px). Listamos qué se ve mal: todo diminuto, una imagen que se sale, un botón chico.
  2. Viewport + imagen flexible. Lo agregamos en el <head> y cambiamos el ancho fijo por width: 100%; max-width: 600px;.
  3. Una media query al final de style.css: botón más grande y título más chico en pantallas de 600px o menos.
  4. Verificamos en modo celular y computadora: ¿se arregló y no se rompió nada?

Bloque 3 · Práctica ≈25 min · Ahora tu sitio

Cuatro pasos, con una IA de ayudante

  1. Diagnóstico propio (≈5). Tu sitio en modo celular: anotá 3 cosas que se ven mal. Después mirá también el modo computadora.
  2. Arreglo base (≈5). Viewport en el <head> y anchos fijos que desbordan → % o max-width.
  3. Ayudante de IA (≈10). Para lo que no supiste resolver (siguiente diapositiva).
  4. Verificación (≈5). Modo celular y modo computadora otra vez. Anotá qué te respondió la IA y si te sirvió.
