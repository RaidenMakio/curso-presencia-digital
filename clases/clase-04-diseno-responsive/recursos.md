# Recursos — Clase 4: Diseño responsive (celular y computadora)

Material **opcional** para profundizar con calma. No hace falta leerlo para la clase ni para la tarea. 🇪🇸 = en español · 🇬🇧 = en inglés (el navegador puede traducirlo).

## Para leer con calma

- 🇪🇸 [Diseño responsivo — MDN](https://developer.mozilla.org/es/docs/Learn_web_development/Core/CSS_layout/Responsive_Design): la explicación oficial de qué es y cómo se logra.
- 🇪🇸 [Usar media queries — MDN](https://developer.mozilla.org/es/docs/Web/CSS/CSS_media_queries/Using_media_queries): sintaxis y ejemplos de `@media`.
- 🇬🇧 [Responsive web design basics — web.dev](https://web.dev/articles/responsive-web-design-basics): el viewport, el contenido flexible y los puntos de quiebre.
- 🇪🇸 [El modelo de caja — MDN](https://developer.mozilla.org/es/docs/Learn_web_development/Core/Styling_basics/Box_model): márgenes, relleno y bordes, la base para ajustar espacios.
- 🇪🇸 [Curso de Diseño Web Responsivo — freeCodeCamp](https://www.freecodecamp.org/espanol/learn/2022/responsive-web-design/): práctica guiada con corrección automática.

## Cheatsheets

- 🇬🇧 [Guía completa de Flexbox — CSS-Tricks](https://css-tricks.com/snippets/css/a-guide-to-flexbox/): un dibujo de cada propiedad; la referencia más usada.
- 🇬🇧 [Guía completa de Grid — CSS-Tricks](https://css-tricks.com/snippets/css/complete-guide-grid/): para cuando quieras acomodar galerías.
- 🇬🇧 [Can I use…](https://caniuse.com/): consulta si una propiedad funciona en todos los navegadores.

## Practicar jugando

- [Flexbox Froggy](https://flexboxfroggy.com/#es): ayudás a unas ranas con `justify-content` y `align-items`.
- [CSS Grid Garden](https://cssgridgarden.com/#es): regás una huerta usando CSS Grid.

## Herramientas para probar tu sitio en distintos tamaños

- 🇬🇧 [Modo dispositivo de Chrome DevTools](https://developer.chrome.com/docs/devtools/device-mode): con F12 y el ícono del celular, simulás cualquier pantalla.
- [Responsively App](https://responsively.app/): muestra tu sitio en varios dispositivos a la vez.
- [Am I Responsive?](https://ui.dev/amiresponsive): pegás la dirección de tu sitio y lo ves en celular, tablet y computadora.

## Usar IA como ayudante (la usamos en clase)

Cualquiera de estos asistentes te sirve para pedir una explicación o una media query. Regla de oro: primero intentá vos, pedí explicación, probá siempre lo que te responde y no pegues datos personales.

- [Gemini](https://gemini.google.com/) · [ChatGPT](https://chatgpt.com/) · [Claude](https://claude.ai/) · [Copilot](https://copilot.microsoft.com/): asistentes de IA con versión gratuita (los límites cambian).
- 🇪🇸 [Usar media queries — MDN](https://developer.mozilla.org/es/docs/Web/CSS/CSS_media_queries/Using_media_queries): para **comprobar** si lo que te respondió la IA está bien escrito.
