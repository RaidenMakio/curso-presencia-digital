# Curso: Crea tu Presencia Digital

Ocho clases para que armes, con tu propio proyecto, un sitio web con identidad visual propia y un link real para compartir. Acá encontrás el material de cada clase a medida que se va subiendo.

## Cómo usar este sitio

- **Clase guiada:** el libreto de las 2 horas de clase, en formato de lectura. Arranca con un resumen para repasar (la vieja "guía de estudio"). Podés seguirlo antes, durante o después de la clase.
- **Presentación:** las diapositivas de la clase. Se abren en una pestaña nueva; usá las flechas del teclado para avanzar.
- **Recursos:** lecturas, cheatsheets, herramientas y documentación externa para profundizar con calma. Son opcionales: no hacen falta para la clase ni para la tarea.
- **Banco de preguntas:** un juego de preguntas para repasar lo que vimos, con corrección al toque. Se abre en una pestaña nueva y arranca solo.
- **Buscador:** arriba a la izquierda, busca dentro de todo este material.

## Bonus (fuera del curso): Trabajar con IA

Un recurso aparte, **de otro curso**, para abrir entre medio de las clases cuando te sirva. No dura nada, no se evalúa y no hace falta para las tareas. Un recorrido corto de 4 pasos para armar tu sitio con IA sin perder el control.

- [Guía y 3 prompts](bonus-ia/guia.md): marca rápida (colores y tipografías), tu sitio desde una plantilla y banners para tus anuncios.
- [Plantilla de tu sitio](bonus-ia/plantilla-sitio.md): la completás con tus datos y se la das al prompt del sitio.
- [Cheatsheet: qué IA usar](bonus-ia/cheatsheet.md): para cada tipo de trabajo (textos, diseño, imágenes, código…), qué IA probar primero, segundo y tercero.
